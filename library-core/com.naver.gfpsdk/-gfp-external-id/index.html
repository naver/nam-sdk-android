GfpExternalId

data class GfpExternalId(val source: String, val id: String)

First-party data (ID solution) identifier delivered to the GFP server with every ad request.

Set the identifiers through com.naver.gfpsdk.properties.UserPropertiesBuilder.setExternalIds, which replaces the previously set identifiers. Several identifiers can share the same source (e.g. multiple Google PAIR IDs).

GfpSdk.setUserProperties(
    GfpSdk.getUserProperties().buildUpon()
        .setExternalIds(
            listOf(
                GfpExternalId(source = "liveramp.com", id = "YOUR_LIVE_RAMP_ENVELOPE"),
                GfpExternalId(source = "google.com", id = "YOUR_GOOGLE_PAIR_ID1"),
                GfpExternalId(source = "google.com", id = "YOUR_GOOGLE_PAIR_ID2")
            )
        )
        .build()
)
